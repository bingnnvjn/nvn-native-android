# ADRs

Decisions that are hard to reverse, or would otherwise live only in a chat thread.

- One file per decision: `NNNN-short-title.md`, starting at `0001`.
- Status line (`proposed` / `accepted` / `superseded by ADR-NNNN`), then context, decision, consequences.
- Link the issue and the code the decision binds.
- If a change contradicts an existing ADR, say so explicitly instead of silently overriding it.

No ADRs yet. See `docs/agents/domain.md` for how the skills consume these files.
